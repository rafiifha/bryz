**Date**: 2026-11-03  
**Project**: Bryz Academic Support  
**Auditor**: Antigravity (Anti-Slop Mode: AFTER)

## Executive Summary
Audit komprehensif terhadap antarmuka web, kode komponen, dan berkas CSS project Bryz Academic Support telah dilakukan. Ditemukan **12 temuan** yang dikelompokkan ke dalam 3 tingkat prioritas:
* **High Priority (Hard Gate)**: 6 temuan (Aksesibilitas, semantik kontrol, link mati, mobile drawer admin, dan em dash).
* **Medium Priority (Purpose-Gate)**: 3 temuan (Ritme seksi repetitif, duplikasi kartu keunggulan, radius kapsul berlebih, dan glassmorphism cap).
* **Low Priority (Quality Locks & UX Focus)**: 3 temuan (Tombol portal admin di box CTA publik, optimasi atribut gambar non-kritis, dan aria-hidden SVG).

Sesuai aturan Anti-Slop Mode AFTER, **tidak ada berkas kode yang diubah**. Perbaikan hanya akan dieksekusi setelah pengguna menyetujui nomor temuan yang ingin diperbaiki.

## Numbered Findings List

### Tier 1: Hard Gate (Priority: HIGH)

#### [1] R-02 — Em dash character in layout metadata title
* **File**: `src/app/layout.tsx` (Line 6)
* **Code**: `title: 'Bryz Academic Support — Jasa Bantuan Akademik Terpercaya'`
* **Rule**: R-02 (FORBIDDEN: em dash character `—` in any text outside documentation structure).
* **Reason**: Penggunaan tanda em dash `—` adalah salah satu penanda paling umum teks tergenerasi AI; ganti dengan tanda hubung standar `-` atau pemisah titik/pipa.

#### [2] R-39 & R-32 — Non-semantic clickable `div` on testimonial screenshot cards
* **File**: `src/components/LandingPage.tsx` (Lines 644–650)
* **Code**: `<div className="testimonial-card" onClick={() => setPreviewImage(t.imageUrl)}>`
* **Rule**: R-39 (REQUIRED: actions are `<button>`, no clickable `div`/`span`) & R-32 (Keyboard Accessibility).
* **Reason**: Kartu tangkapan layar testimoni dapat diklik untuk memperbesar gambar, namun menggunakan elemen `<div>` sehingga tidak dapat diakses atau diaktifkan oleh pengguna keyboard menggunakan tombol `Tab`, `Enter`, atau `Space`.

#### [3] R-39 & R-32 — Non-semantic clickable `div` on FAQ accordion headers
* **File**: `src/components/LandingPage.tsx` (Lines 702–707)
* **Code**: `<div className="faq-item" onClick={() => setActiveFaq(activeFaq === idx ? null : idx)}>`
* **Rule**: R-39 (REQUIRED: interactive toggles must be `<button>`) & R-32 (Keyboard Navigation).
* **Reason**: Header FAQ accordion tidak menggunakan elemen `<button>` atau `<summary>` dan tidak memiliki atribut `aria-expanded`, sehingga tidak bisa dibuka-tutup dengan navigasi keyboard.

#### [4] R-24 & R-26 — Dead anchor link `href="#"` on brand logo in header and footer
* **File**: `src/components/LandingPage.tsx` (Lines 205, 775)
* **Code**: `<a href="#" className="navbar-logo">`
* **Rule**: R-24 (Links must point to real accessible destinations) & R-26 (No dead links).
* **Reason**: Tautan logo mengarah ke `#` tanpa rute jelas yang menyebabkan lompatan scroll kasar alih-alih mengarahkan pengguna kembali ke root `/`.

#### [5] R-32 & R-39 — Missing Escape key handler & `aria-label` on admin dashboard modals
* **File**: `src/app/admin/dashboard/page.tsx` (Lines 1080–1092, 1175–1185)
* **Code**: Modal service dan testimonial tidak mendengarkan event `Escape`, dan tombol `✕` tidak memiliki `aria-label`.
* **Rule**: R-32 (Modals must be closable with Escape) & R-39 (Every control has an accessible name).
* **Reason**: Pengguna keyboard tidak dapat menutup pop-up modal di admin dengan tombol `Escape`, dan pembaca layar tidak dapat membaca fungsi tombol `✕`.

#### [6] R-03 — Admin dashboard navigation completely inaccessible on mobile viewports
* **File**: `src/app/globals.css` (Lines 1505–1512)
* **Code**: `@media (max-width: 768px) { .admin-sidebar { display: none; } }`
* **Rule**: R-03 (Mobile layout must be functional, not an afterthought).
* **Reason**: Pada layar HP, sidebar admin dihilangkan seluruhnya tanpa menyediakan tombol menu atau tab switcher pengganti, sehingga admin tidak dapat berpindah ke tab Testimoni maupun Pengaturan dari smartphone.

### Tier 2: Purpose-Gate (Priority: MEDIUM)

#### [7] R-05 & R-14 — Monotonous 3-in-a-row card grids and redundant "Keunggulan" section
* **File**: `src/components/LandingPage.tsx` (Lines 526–555, 567–577)
* **Rule**: R-05 (Uniform section rhythm forbidden) & DESIGN.md §1.3 (RHYTHM: 2).
* **Reason**: Tiga section berturut-turut (Layanan, Keunggulan, Alur Pemesanan) menggunakan layout grid kartu yang identik dengan emoji besar. Terlebih, section Keunggulan mengulang poin garansi yang sudah disampaikan di Hero Trust Pillars. Alur Pemesanan lebih baik divisualisasikan sebagai timeline horizontal/pipeline yang terhubung.

#### [8] R-11 — Excessive full-pill border radius on rectangular price tags
* **File**: `src/app/globals.css` (Lines 637–646) & `src/components/LandingPage.tsx` (Line 333)
* **Code**: `.service-price-pill { border-radius: var(--radius-full); }`
* **Rule**: R-11 (FORBIDDEN: making every element pill-shaped) & DESIGN.md §6.1.
* **Reason**: Menggunakan radius kapsul 9999px pada blok harga teks panjang menimbulkan kesan AI template; ubah ke radius modular terkalibrasi (`var(--radius-sm)` / 8px).

#### [9] R-10 — Glassmorphism dose cap violation on floating action button
* **File**: `src/app/globals.css` (Lines 984–998)
* **Code**: `.floating-qris { backdrop-filter: blur(12px); -webkit-backdrop-filter: blur(12px); }`
* **Rule**: R-10 (Dose cap: blur/backdrop-filter on at most 1–2 elements simultaneously).
* **Reason**: Penggunaan backdrop filter secara bersamaan di navbar, floating button, dan modal overlay melanggar batas dosis; tombol QRIS sebaiknya menggunakan solid background `--bg-card` dengan border yang tajam dan kontras.

### Tier 3: Quality Locks & UX Alignment (Priority: LOW)

#### [10] C-3 & UX Focus — Admin Portal link inside client urgent deadline CTA box
* **File**: `src/components/LandingPage.tsx` (Lines 761–764)
* **Code**: `<a href="/admin" className="btn btn-secondary btn-lg"><span>Portal Admin</span></a>`
* **Rule**: C-3 (Content-driven composition) & DESIGN.md §9.1 (Client conversion focus).
* **Reason**: Box CTA berfokus pada urgensi deadline mahasiswa ("Deadline Sudah Dekat? Jangan Ditunda Lagi!"). Menyertakan tombol Portal Admin tepat di samping tombol WhatsApp mendisrupsi alur konversi calon klien dan membingungkan pengguna publik (link admin sudah tersedia di footer).

#### [11] R-40 — Missing lazy loading & async decoding on testimonial screenshot images
* **File**: `src/components/LandingPage.tsx` (Lines 650–654)
* **Code**: `<img src={t.imageUrl} alt={...} className="testimonial-image" />`
* **Rule**: R-40 (Performance mechanisms, image loading attributes).
* **Reason**: Gambar tangkapan layar testimoni di bawah halaman belum menyertakan atribut `loading="lazy"` dan `decoding="async"` untuk mencegah penurunan skor LCP/CLS pada koneksi seluler.

#### [12] R-39 — Missing `aria-hidden="true"` on decorative SVGs inside ThemeToggle button
* **File**: `src/components/ThemeToggle.tsx` (Lines 21, 33)
* **Code**: `<svg width="17" height="17" viewBox="0 0 24 24" ...>`
* **Rule**: R-39 (Accessible semantics: icons inside labeled controls must be hidden from screen readers).
* **Reason**: Ikon matahari dan bulan berada di dalam tombol yang sudah memiliki `aria-label`, sehingga ikon SVG wajib ditandai `aria-hidden="true"` agar tidak dibaca ganda oleh screen reader.
